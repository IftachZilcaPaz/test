# מחקר ספקים ועלויות — reynovation (ספטמבר 2026)

## Higgsfield API (מדיה: וידאו ותמונות)
- מפתח נוצר ב-console/open.higgsfield.ai, מורכב מ-key id + secret: `Authorization: Key ID:SECRET`. בשרת בלבד.
- תהליך: POST ליצירה → polling ל-`/requests/{id}/status` (או webhook) → כתובת הקובץ. יש endpoint `estimate` שמחזיר מחיר לפני הרצה.
- חיוב: יתרה מראש, בדולרים/קרדיטים. בקשה שנכשלה או נחסמה (nsfw) לא מחויבת. קרדיטים פגים אחרי שנה. תוצרים נשמרים לפחות 7 ימים — להוריד לאחסון שלנו.
- מדריך ה-Quick start הרשמי מתאר זרימת "Connect API key" שבה משתמש קצה מדביק מפתח משלו — כלומר הזרימה הזו נתמכת.
- תנאי שימוש (API Terms): אסור לחשוף את ה-API או המפתח ישירות למשתמש (4.1), אסור למכור גישה "כמו שהיא" (4.2); מותר כשהאפליקציה מוסיפה ערך משמעותי (כמו שלנו). חובה תנאי שימוש מול הלקוחות שלנו שמגנים לפחות כמו שלהם (4.4). בעל המפתח אחראי לכל שימוש בו (2.1).
- **אין קריינות (TTS) ב-API** — רק וידאו ותמונה.

## קריינות: ElevenLabs API
- $0.10 ל-1,000 תווים (Eleven v3 / Multilingual v2), $0.05 ל-Flash/Turbo.
- הקולות שבחרנו (Grady וכו') הם קולות ElevenLabs שרצו דרך Higgsfield — לבדוק שאותם קולות והגייה זמינים ישירות.
- **נבדק (27.9.2026) על תסריט 1ב עם הקול Roger:**
  - `eleven_v3` + `language_code: "he"` — **5/5**, ההגייה מעולה כולל "מֶנְטוֹר אִיט". **זה המודל שלנו.**
