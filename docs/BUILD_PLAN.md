# reynovation — תוכנית בנייה לאפליקציה העצמאית

המטרה: לקוח שלא יודע כלום על AI נכנס, מספר על העסק בעברית, ויוצא עם סרטון פרומו מוכן —
וכל שלב שעולה כסף מוצג לו במחיר מדויק בשקלים לפני שהוא מאשר.

## הזרימה של הלקוח (5 מסכים)
1. **העסק שלי** — שם, מה עושים, קהל, מה הצופה צריך לעשות, צילומי מסך/תמונות, מילון ניקוד.
2. **תסריט** — 3 גרסאות באורך מחושב, עריכה, אישור.
3. **קול** — גלריית קולות עם דגימה מוכנה לכל קול (בחינם ללקוח), ודגימה של *התסריט שלו* בקול שבחר (~2 סנט).
4. **סצנות** — סצנות AI בלי טקסט על המסך (Higgsfield), מחיר מדויק מ-`estimate` לפני כל סצנה.
5. **הסרטון** — טיוטה → בדיקות (כיתוב מצטט קריינות, תזמון, הגייה) → סרטון סופי להורדה.

## ארכיטקטורה
| שכבה | בחירה | למה |
|---|---|---|
| אתר ואפליקציה | Next.js + TypeScript, עברית RTL, עיצוב הלילך | תבנית ה-Studio של Higgsfield API בנויה על Next.js; מוכר ונפוץ |
| מסד נתונים + קבצים | Postgres + אחסון קבצים (S3/R2) | פרויקטים, תסריטים, מילונים, יתרות; תוצרי Higgsfield נמחקים אחרי 7 ימים — שומרים אצלנו |
| תסריטים | Claude API (Opus 5), פלט מובנה | כבר יש לנו את הפרומפט והכללים ב-`video/generator` |
| קריינות | ElevenLabs `eleven_v3` + `language_code: he` | נבדק: 5/5 |
| תזמון מילים | ElevenLabs Forced Alignment | מחליף את Whisper לסנכרון כיתובים |
| סצנות | Higgsfield API (Seedance 2.0/2.5) + webhook | מחיר מראש, בלי חיוב על כישלון |
| הרכבה | שרת עבודה בקונטיינר: ffmpeg + Chromium (Playwright) + Python | המנוע שלנו מ-`video/engine`, בלי התלות ב-higgsedit |
| תשלום | ארנק קרדיטים בשקלים + ספק סליקה | הלקוח רואה ₪, אנחנו משלמים לספקים בדולר |

כל המפתחות (Claude, ElevenLabs, Higgsfield) יושבים בשרת בלבד. אופציה בהמשך: לקוח שמחבר מפתח Higgsfield משלו, עם מדריך בעברית.

## שלבים
| # | שלב | מה יוצא ממנו | עלות API לפיתוח (הערכה) |
|---|---|---|---|
| 0 | שלד ✅ | אתר רץ מקומית, RTL, עיצוב, התחברות, מסד נתונים — ב-`app/` | 0 |
| 1 | תסריט ✅ | מסך 1–2 עובדים מקצה לקצה (כולל מצב דמו חינמי) | ~$1 (בדיקות Claude) |
| 2 | קול | גלריית קולות (דגימות נוצרות פעם אחת ונשמרות), קריינות + תזמון | ~$1 |
| 3 | סצנות | מסך 4 עם מחיר מראש, העלאת תמונות | ~$3–5 (כמה סצנות בדיקה) |
| 4 | הרכבה | המנוע בקונטיינר, טיוטה + סרטון סופי | ~$1 |
| 5 | כסף | ארנק, מחירון בשקלים, סליקה | 0 |
| 6 | עלייה לאוויר | דומיין, אחסון, ניטור, תנאי שימוש (חובה לפי תנאי Higgsfield API) | עלות אחסון חודשית |

כל שלב נגמר במשהו שאפשר ללחוץ עליו ולבדוק. לפני כל הוצאה על API — מחיר ואישור.

## פתוח (חוזרים אליו)
- בחירת קולות לגלריה (הלקוח שומע ובוחר; צריך ~6–10 קולות עבריים טובים).
- מחיר מדויק לסצנה מ-Higgsfield `estimate` (דורש מפתח Higgsfield API).
- ספק סליקה וחברת אחסון.
